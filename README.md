# SmartFitnessPlanner

## About the Project
Smart Fitness Planner is a web-based application designed to help users plan and manage their fitness activities. It provides an exercise library, workout planning, and progress tracking features to make fitness management simple and organized.

## Features
- User Registration and Login
- Exercise Library
- Workout Planning
- Fitness Progress Tracking
- AI-Based Workout Recommendations

## Technologies Used
- **Frontend:** HTML, CSS, JavaScript
- **Backend:** C# with ASP.NET Web Forms
- **Database:** Microsoft SQL Server
- **IDE:** Visual Studio 2022
- **Database Tool:** SQL Server Management Studio (SSMS)

## Project Modules
1. **User Authentication:** Allows users to register and log in.
2. **Exercise Library:** Displays available exercises.
3. **Exercise Planning:** Helps users create workout plans.
4. **Progress Tracking:** Allows users to record their fitness progress.
5. **AI Recommendations:** Provides workout suggestions based on user preferences.

## Installation and Setup
1. Clone or download this repository.
2. Open the project in Visual Studio 2022.
3. Configure the Microsoft SQL Server connection string in `Web.config`.
4. Create the required database and tables.
5. Build and run the project using Visual Studio.
